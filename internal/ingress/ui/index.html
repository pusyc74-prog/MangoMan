            What can Guardian reach?

            Guardian adds a guardian.json file, a line to .gitignore and a branch called dev for its safe copy. Your live branch only changes when you approve.

            How Guardian works
            1. WatchesEvery 5 minutes: is the app up and quick? Once a day: up to 10 pages in a real browser, the security certificate and the domain dates. Every hour: the journeys you add.
            2. Finds the causeWhen something fails, it shows the error, where it happens and the likely reason, from the error and, when it has your code, your latest changes.
            3. Helps fix itWithout your code, it writes a fix request to paste into the tool you built with. With your code, it writes the fix in a safe copy, has a test written for it and tests it there.
            4. Asks you firstA fix goes live only after you approve it, and is tested again there. If that fails, Guardian puts the last good version back.
